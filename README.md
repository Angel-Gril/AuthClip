# Claude 授权工作台

管理员分配任务，普通用户在手机或电脑上打开任务链接，按教程在 Claude 官方流程中操作，然后提交结果。双方在任务页看到同一条实时进度。网站使用独立账号登录，表单收集邮箱、国家或地区、处理结果和选填的公网 IP。

## Windows 启动

在本目录打开 PowerShell。先创建一个管理员账号和一个普通用户账号，命令会提示输入各自的密码。下面的邮箱可以换成实际使用的工作台邮箱。

```powershell
.\portal.exe account admin@example.com admin
.\portal.exe account member@example.com member
.\portal.exe serve --http 127.0.0.1:8090
```

在电脑打开 <http://127.0.0.1:8090>。管理员点击「分配任务」，选择接收人和教程，然后在任务页点击「复制任务链接」。接收人使用对应的工作台账号登录，页面会直接打开这条任务。

选好接收人后也可以点击「复制接收人的长期入口」。接收人保存这条链接，下次直接打开即可查看新任务和仍在保留期内的历史。

同一 Wi-Fi 内用手机试用时，将监听地址换成 `0.0.0.0:8090`。在手机浏览器打开电脑的局域网地址（例如 `http://192.168.1.10:8090`）。手机连接需要路由器和电脑允许访问端口 8090。使用手机访问的地址登录管理员端后复制链接，这样生成的链接在手机上也能打开。正式使用时以 HTTPS 地址访问。

## Linux 服务器部署

Linux x86_64 部署包包含程序、本地 GeoIP 库、systemd 服务和 Caddy 配置示例。部署包使用内置 SQLite。见 [Linux 部署说明](deploy/部署说明.md)。

## 任务和历史

- Claude Team 邀请通过 Claude 官方发送。管理员可在任务页切换官方入口并发布更新，用户打开原任务就能看到新入口。
- 双方都可以打开或复制任务中的 Claude 公开官方入口，也可以复制任务链接。
- Claude Code 登录和重新登录都由用户在自己的终端发起。工作台记录操作状态和提交资料，登录凭证在 Claude 官方流程中使用。
- 用户提交后，管理员可以审阅并复制邮箱、IP 和地区。
- 用户提交完成结果后，管理员确认，任务自动进入双方的历史。历史从确认起保留 7 天，服务每 15 分钟和每次启动时清理到期任务。处理中的任务链接持续有效。
- 任务内容需要登录，并且仅分配给该任务的用户和管理员可读取。未登录访问显示通用登录页。站点设置了禁止索引和登录限流。

## 地区和界面语言

用户手动选择的语言优先，其次按 IP 所在国家或地区选择支持的语言。遇到无法定位的 IP 时，按浏览器语言选择，最后使用英语。阿拉伯语页面和表单支持从右到左排列。

普通用户可在表单点击「读取当前 IP」，把这次访问的公网 IP 和对应地区填进表单，也可以手填或留空。点提交后，管理员可看到用户填写的 IP。工作台的访问日志关闭了 IP 记录。通过环回或局域网访问时，服务端接收到的通常是内网地址，读取公网 IP 的按钮会提示手填。

本地 IP 归属数据库默认位于 `geo/country.mmdb`。数据库可从 DB-IP 下载 Country Lite MMDB，解压并替换该文件后重启。GeoIP 数据由 DB-IP 提供，采用 CC BY 4.0 授权。[DB-IP Country Lite](https://db-ip.com/db/download/ip-to-country-lite)

使用反向代理时，可通过 `PORTAL_TRUSTED_PROXY` 指定代理的 CIDR，例如 `127.0.0.1/32`。代理应覆盖设置 `X-Real-IP` 为实际客户端地址，并限制后端只接受该代理的访问。未配置时使用直连地址。也可通过 `PORTAL_GEO_DB` 指定本地数据库路径。

go test ./...
node --test tests/locale.test.mjs
